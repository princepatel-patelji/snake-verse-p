# Prince's SnackVerse
**Eat. Play. Puzzle. Repeat!**  
A premium virtual food & puzzle game with friends, communities, and multiplayer challenges.

## 🛠️ Setup Instructions (Windows + VS Code)

### Step 1: Prerequisites
- Install [Node.js LTS](https://nodejs.org/)
- Install [Visual Studio Code](https://code.visualstudio.com/)
- Create a free [Supabase Account](https://supabase.com/)

### Step 2: Create Project
1. Open terminal in desired folder.
2. Run: `mkdir princes-snackverse && cd princes-snackverse`
3. Create all folders/files exactly as shown in the project tree.
4. Paste each file's code into VS Code.

### Step 3: Install Dependencies
